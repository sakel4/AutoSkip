# AutoSkip: Ads Auto Skip Extension for Youtube & Youtube Music 

A lightweight, open-source browser extension that automatically presses the **Skip Ad** button on YouTube and YouTube Music when it becomes available.

The goal is simple: let videos and music keep playing without requiring you to return to your computer just to press **Skip**.

## Why I Built This

I often have YouTube or YouTube Music playing in the background while I am working, doing something else, or away from my computer.

Skippable ads become particularly annoying in those situations because the ad may already be ready to skip, but playback remains interrupted until I manually return to the browser and press the button.

At the same time, I don't necessarily want to remove advertising completely. I want to continue supporting the creators I watch and listen to.

That is why this extension is designed around **automatically pressing YouTube's existing Skip button**, rather than blocking advertisements entirely.

It also includes a configurable **skip delay**, allowing an ad to continue playing for a chosen amount of time after the Skip button becomes available.

> Creator compensation and ad attribution are ultimately determined by YouTube and its advertising systems. Allowing an advertisement to play for a period of time does not guarantee that a creator will receive revenue from that particular impression.

## Features

* **Automatic ad skipping**
  Detects when YouTube's Skip Ad button becomes available and activates it automatically.

* **YouTube support**
  Designed to work while watching regular YouTube videos.

* **YouTube Music support**
  Also designed for background music playback on YouTube Music.

* **Configurable skip delay**
  Choose how long the extension should wait after the Skip button becomes available before activating it.

* **Optional in-player notifications**
  Display a small notification when an ad has been automatically skipped.

* **Enable / disable at any time**
  Auto-skipping can be turned on or off directly from the extension popup.

* **No ad removal**
  The extension does not attempt to remove ads from the page. It waits for YouTube to provide its normal Skip button and then activates it.

* **Open source**
  The source code is publicly available so anyone can inspect how the extension works, report problems, suggest improvements, or contribute.

## How It Works

YouTube does not treat a JavaScript call such as:

```js
button.click();
```

the same way as a physical user click.

The Skip Ad button checks whether the click event was generated by a trusted browser interaction. A normal JavaScript-generated event is marked as:

```js
event.isTrusted === false
```

and may therefore be rejected.

This extension takes a different approach:

1. A content script watches the YouTube player for a visible Skip Ad button.
2. When the button becomes available, the extension waits for the configured skip delay.
3. The button is checked again after the delay to make sure it is still visible.
4. Its current position inside the browser viewport is calculated.
5. The extension's background service worker uses the Chrome DevTools Protocol through `chrome.debugger`.
6. A browser-level mouse press and release are dispatched at the Skip button.
7. YouTube receives the interaction and processes its normal Skip Ad behavior.

Conceptually:

```text
Ad starts
    ↓
Skip button becomes available
    ↓
Extension detects the button
    ↓
Optional user-defined delay
    ↓
Button position is recalculated
    ↓
Browser-level click is dispatched
    ↓
YouTube handles its normal Skip action
    ↓
Playback continues
```

## Settings

The extension popup currently provides the following options:

### Enable auto-skip

Turns automatic skipping on or off.

### Show notifications

When enabled, a small temporary notification is displayed over the player after an ad is skipped.

### Skip delay

Controls how long the extension waits after the Skip button becomes available.

For example:

```text
Instant ─────────────── 3s
```

A longer delay can be useful if you prefer to allow part of the advertisement to continue playing before it is skipped.

## Permissions

The extension intentionally keeps its permission requirements small.

### `storage`

Used to store preferences such as:

* Whether auto-skip is enabled
* Whether notifications are enabled
* The selected skip delay

These settings are stored using Chrome's extension storage API.

### `debugger`

This permission is required because YouTube rejects ordinary synthetic JavaScript clicks on its Skip Ad button.

The extension uses `chrome.debugger` only to dispatch the mouse input required to activate the visible Skip Ad control.

The extension is **not intended to use the debugger permission to inspect network traffic, read page debugging information, modify scripts, or perform unrelated browser debugging operations**.

Because this project is open source, the exact debugger commands used by the extension can be inspected directly in the source code.

## Privacy

The extension is designed with privacy in mind.

It does not require an account and is not intended to:

* Collect browsing history
* Track which videos you watch
* Track which creators you watch
* Collect advertisement information
* Collect personal information
* Send analytics to an external server
* Sell or share user data

User preferences are stored using the browser's extension storage system.

If this changes in the future, the privacy documentation should be updated before such functionality is introduced.

## Installation

### Install from source

Until the extension is available through a browser extension store, it can be installed manually.

1. Clone or download this repository.

```bash
git clone <repository-url>
```

2. Open Chrome and navigate to:

```text
chrome://extensions
```

3. Enable **Developer mode**.

4. Select **Load unpacked**.

5. Select the directory containing `manifest.json`.

6. Open YouTube or YouTube Music.

The extension should now be active.

## Project Structure

A simplified version of the extension structure looks like:

```text
extension/
├── manifest.json
├── background.js
├── content.js
├── popup.html
├── popup.js
├── popup.css
└── icons/
```

### `content.js`

Responsible for:

* Detecting the Skip Ad button
* Checking whether it is visible
* Managing the configured delay
* Calculating the latest button coordinates
* Displaying optional notifications
* Communicating with the background service worker

### `background.js`

Responsible for:

* Receiving skip requests from the content script
* Attaching the Chrome debugger API
* Dispatching browser-level mouse input
* Detaching after the interaction completes

### `popup.html`, `popup.css`, `popup.js`

Provide the extension settings interface and store user preferences.

## Development

After modifying extension files:

1. Open:

```text
chrome://extensions
```

2. Press **Reload** on the extension.

3. Reload any existing YouTube or YouTube Music tabs.

Reloading the page is important because an already injected content script belongs to the previous extension context and cannot continue using extension APIs after the extension itself has been reloaded.

## Design Philosophy

The project follows a few basic principles:

**Do one thing well.**
Automatically activate an available Skip Ad button without trying to redesign or replace YouTube's advertising system.

**Respect user choice.**
Users can disable the extension, choose whether notifications appear, and decide how long to wait before skipping.

**Keep it lightweight.**
The extension uses event-driven DOM observation and scheduled timers rather than continuously polling the page.

**Keep it transparent.**
The code is open source so users can see exactly what the extension does, especially given the powerful `debugger` permission required for the click mechanism.

**Avoid unnecessary data collection.**
Skipping an ad does not require an external account, analytics service, or remote server.

## Known Limitations

YouTube frequently changes its player UI and internal implementation.

Selectors such as those used to locate the Skip Ad button may therefore change over time and require updates.

The extension also relies on browser functionality that may behave differently between Chromium-based browsers.

If YouTube changes the way its Skip button validates interactions, the extension's click mechanism may also need to be updated.
